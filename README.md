# ML Problem Framing & Responsible Data Card — Customer Churn

## Files
- `ml_problem_framing_memo.md` — decision, target, baseline, costs, abstention, monitoring, rollback, and go/no-go conditions.
- `responsible_data_card.md` — provenance, population, features, quality, risks, safeguards, and evaluation.
- `risk_register.md` — structured risk register.
- `baseline_churn.ipynb` — reproducible data audit and baseline notebook.
- `customer-churn-training.csv` — supplied training data used by the notebook.

## Important limitation
The supplied dataset has only 12 rows and no timestamps, provenance/consent metadata, or train/test split. Results are therefore for workflow demonstration only and should not be treated as production performance.
